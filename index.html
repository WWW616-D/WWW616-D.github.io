Q-Learning 核心公式

一、核心公式

$$
Q(s,a) \leftarrow Q(s,a) + \alpha \left[ r + \gamma \max_{a’} Q(s’,a’) - Q(s,a) \right]
$$

二、符号含义

符号 含义
$Q(s,a)$ 在状态 $s$ 做动作 $a$ 的价值评分
$r$ 做动作后立刻得到的奖励
$\gamma$ 折扣因子（未来奖励的打折率，常用 0.95）
$\max Q(s’,a’)$ 在新状态下未来能得到的最高评分
$\alpha$ 学习率（新信息覆盖旧信息的速度，常用 0.1）

三、一句话理解

新评分 = 旧评分 + 学习率 × (实际拿到的 + 未来预期的 - 旧评分)

四、代码实现

五、三种特殊情况

情况 公式变化
正常 $Q \leftarrow Q + \alpha [r + \gamma \max Q(s’) - Q]$
终止状态 $Q \leftarrow Q + \alpha [r - Q]$（没有 $\gamma \max Q(s’)$）
撞墙（状态不变） 同上，$s’ = s$，$Q$ 依然更新

六、完整算法伪代码

关于GD-UAP方法

Posted on 2026-08-06 Edited on 2026-08-10

基本原理：

深度学习模型对输入
x和扰动δ并非完全线性，但存在相关性。即
f(x+δ)−f(x) 与 f(δ)高度相关。为什么这个相关性存在？
深层网络虽不是严格的线性系统，但ReLU等激活函数在局部近似线性。因此，扰动δ本身在网络中引发的“特征响应模式”，与它叠加到真实图片x上后引发的“特征变化模式”高度一致。
换句话说：“δ的独立激活方向”就是“δ对x的破坏方向”。因此，最大化 f(δ）（即单独输入扰动时的特征响应），往往能在真实输入上产生显著的输出变化。

UAP历史发展:

早期考虑是对一组图片进行deepfool(最短距离扰动)扰动叠加，也就是对于无法欺骗的图片，用deepfool生成它的最小扰动然后加到累计的扰动上，如果已经可以欺骗，则跳过这个图片。

早期方法缺点:

需要大量数据，可能会因为叠加导致毁坏原先结构需反复验证，计算量庞大。且非完全黑盒，不切实际,以及愚弄的概念可能需要专门设计

细碎想法

很让人惊讶的一点是:即使经过打印、光照变化、角度倾斜、摄像头传感器噪声等物理失真，对抗样本依然能骗过模型。这与我之前对对抗样本这种细微扰动的直觉判断是不符合的。
这里还提到range prior的做法，按照高斯分布生成随机数据d来模拟真实的x，防止扰动脱离实际，但是随机生成的数据d本身缺乏意义性，是否会对训练有影响？

L2 范数（能量）比均值更能代表“神经元整体兴奋程度”，连乘迫使所有层都充分激活，因此 GD-UAP 更强。

# GD-UAP 算法流程

---

## 算法输入输出

| 项目 | 说明 |
| :--- | :--- |
| **输入** | 目标CNN模型 `f`，数据载体 `g`（0 / 伪数据 / 真实数据） |
| **输出** | 通用扰动 `δ` |
| **超参数** | 限幅 ξ=10，学习率 η=0.1，饱和率阈值 θ=1e-5 |


## 算法步骤

# GD-UAP 算法流程

## 一、输入与输出

- **输入**：目标CNN模型 f，数据载体 g（g=0 或 g=伪数据 d 或 g=真实数据 x）
- **输出**：通用扰动 δ
- **超参数**：ξ=10，η=0.1，θ=1e-5，H（耐心值）


## 二、算法步骤

1. **初始化**
   - 随机初始化 δ₀ ~ U[-ξ, ξ]
   - t = 0
   - F_t = 0

2. **循环迭代**（重复执行以下步骤）

   - **2.1 采样数据载体 g**
     - No Prior：g = 0
     - Range Prior：g = 高斯伪数据 d（随机裁剪+增强）
     - Data Prior：g = 真实图片 x（随机采样）

   - **2.2 前向传播**
     - 计算各层特征图：l₁(g+δ)，l₂(g+δ)，...，l_K(g+δ)
     - 只刺激卷积层，不碰全连接层

   - **2.3 计算损失**
     - Loss = -∑ log( ∏ ||l_i(g+δ)||₂ )
     - 连乘：确保每一层都被充分激活
     - 取对数：防止数值下溢

   - **2.4 反向传播与更新**
     - 计算梯度：∇_δ(Loss)
     - 梯度上升更新：δ ← δ + η · ∇_δ(Loss)
     - 限幅：δ ← clip(δ, -ξ, ξ)
     - 注意：模型权重冻结，只更新 δ

   - **2.5 自适应缩放**
     - 计算饱和率 S_t（像素值 == ±ξ 的比例）
     - if S_t 增长速度 < θ：
       - δ ← δ / 2（释放空间，保留方向模式）

   - **2.6 验证**
     - 每 200/400 步在验证集 D 上测试愚弄率 F_t

3. **收敛判断**
   - if F_t 连续 H 次不再提升：
     - 停止迭代

4. **返回结果**
   - j ← argmax(F_t)
   - return δ_j


## 三、核心损失函数

> Loss = -∑ log( ∏ ||l_i(g+δ)||₂ )

- l_i：第 i 层卷积层的输出特征图
- ||·||₂：L2范数（该层总能量）


## 四、三种数据模式

| 模式 | 载体 g | 说明 |
| :--- | :--- | :--- |
| No Prior | g = 0 | 纯黑背景，完全无数据 |
| Range Prior | g = d | 高斯伪数据，使用数据均值和动态范围 |
| Data Prior | g = x | 真实训练样本，仅作对比 |


## 五、一句话总结

> 通过梯度上升最大化CNN中间层的激活能量，在纯噪声或伪数据上学习，生成无需真实数据的通用对抗扰动。

关于 "DeepFool: a simple and accurate method to fool deep neural networks"

Posted on 2026-08-02

阅读过程碎语

目的是验证评估模型对对抗性扰动的抗性？

所以需要一种更好的生成扰动的方法，这个方法兼顾了准确性和最优性和效率

这种方法尝试去寻找决策边界，然后找到样本与决策边界的垂直方向。

仿射变换 = 线性变换 + 平移

当边界是曲线的时候，认为最短路线会是曲线，于是不断迭代取切线方向行走

        在对抗扰动通常走过的这条小路径上，深度网络的决策函数表现出惊人的局部线性

对抗样本往往来自局部线性敏感性

对于多分类问题，寻找边界最近的类，再寻求对其的最小扰动

把当前位置线性化？根据梯度计算扰动变化，根据变化后相等联立等式，

DeepFool 核心公式

公式(8) —— 寻找最近边界

$$
\hat{l}(\mathbf{x}_0) = \underset{k \neq \hat{k}(\mathbf{x}_0)}{\arg\min} \frac{|f_k(\mathbf{x}0) - f{\hat{k}(\mathbf{x}_0)}(\mathbf{x}_0)|}{|\mathbf{w}k - \mathbf{w}{\hat{k}(\mathbf{x}_0)}|_2}
$$

公式(9) —— 垂直投影扰动

$$
\mathbf{r}_*(\mathbf{x}0) = \frac{|f{\hat{l}(\mathbf{x}_0)}(\mathbf{x}0) - f{\hat{k}(\mathbf{x}_0)}(\mathbf{x}0)|}{|\mathbf{w}{\hat{l}(\mathbf{x}0)} - \mathbf{w}{\hat{k}(\mathbf{x}_0)}|2^2} (\mathbf{w}{\hat{l}(\mathbf{x}0)} - \mathbf{w}{\hat{k}(\mathbf{x}_0)})
$$

公式(15) —— 全局平均鲁棒性

$$
\hat{\rho}{\mathrm{adv}}(f) = \frac{1}{|\mathcal{D}|} \sum{\mathbf{x} \in \mathcal{D}} \frac{|\hat{\mathbf{r}}(\mathbf{x})|_2}{|\mathbf{x}|_2}
$$

非线性多分类 —— 局部线性化多面体（公式10）

$$
\hat{P}i = \bigcap{k=1}^c \left{ \mathbf{x} : f_k(\mathbf{x}i) - f{\hat{k}(\mathbf{x}_0)}(\mathbf{x}_i) + \nabla f_k(\mathbf{x}i)^\top \mathbf{x} - \nabla f{\hat{k}(\mathbf{x}_0)}(\mathbf{x}_i)^\top \mathbf{x} \leq 0 \right}
$$

算法2中的局部变量定义（非线性多分类每步计算）

对每个类别 (k \neq \hat{k}(\mathbf{x}_0))，在当前点 (\mathbf{x}_i) 处线性化后：

$$
f_k’ = f_k(\mathbf{x}i) - f{\hat{k}(\mathbf{x}_0)}(\mathbf{x}_i)
$$

$$
\mathbf{w}_k’ = \nabla f_k(\mathbf{x}i) - \nabla f{\hat{k}(\mathbf{x}_0)}(\mathbf{x}_i)
$$

最近边界的索引（非线性版本，对应公式8的扩展）

$$
\hat{l} = \arg\min_{k \neq \hat{k}(\mathbf{x}_0)} \frac{|f_k’|}{|\mathbf{w}_k’|_2}
$$

每步的扰动更新（非线性版本，对应公式9的扩展）

$$
\mathbf{r}i = \frac{|f{\hat{l}}’|}{|\mathbf{w}_{\hat{l}}’|2^2} , \mathbf{w}{\hat{l}}’
$$

位置更新

$$
\mathbf{x}_{i+1} = \mathbf{x}_i + \mathbf{r}_i
$$

迭代停止条件

$$
\hat{k}(\mathbf{x}_{i+1}) \neq \hat{k}(\mathbf{x}_0)
$$

最终扰动输出

$$
\hat{\mathbf{r}} = \sum_i \mathbf{r}_i
$$

可以通过先降维再升维的方式改进V的大小，这个方法叫做对大矩阵的低秩分解。
先编码理解，再逐词解码生成,训练过程通过掩码以及强制塞正确答案作为输入的设计，使得训练可以并行计算。
