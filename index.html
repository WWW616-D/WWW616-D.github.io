关于Adversarial Reinforcement Learning for Large Language Model Agent Safety

Posted on 2026-08-16 Edited on 2026-08-17

基本想法

  • 先用成熟模型进行回合预训练，通过监督学习数据得到攻击model和防御model，做一定的微调确保基础功能不丧失
  • 再开始模拟训练，设计稀疏奖励反复对抗进行强化学习

一、整体框架（核心思想）

ARLAS 同时训练两个模型：

  • 攻击者（Attacker）：生成间接提示注入（恶意文本），插入到智能体观察到的网页/邮件内容中。
  • 智能体（Agent）：执行任务（如订机票），同时要抵抗注入，不泄露用户信息。

两者通过**强化学习（RL）**对抗式共同进化。

二、问题建模（形式化）

将问题建模为双人博弈，每个回合包含多个时间步：

  • 每个时间步：
    1. 攻击者根据当前状态 ( s ) 生成提示注入 ( a_{atk} )
    2. 智能体根据状态 + 用户信息 + 注入内容，选择工具调用 ( a_{agt} )
  • 回合结束时，根据结果给出稀疏奖励（只在最后一步给）：
结果 攻击者奖励 智能体奖励
泄露用户信息 +1 -1
任务成功且未泄露 -1 +1
任务失败或超时 -1 -1
其他（未结束） 0 0

目标是：攻击者最大化自己的奖励，智能体最大化自己的奖励。

三、训练流程（三个阶段）

阶段 1：预热——模仿学习（Imitation Learning）

目的：避免两个模型一开始随机探索效率太低。

做法：

  1. 使用更强的大模型（如 27B/32B）收集 1 万条完整回合数据。
  2. 只保留攻击者成功或智能体成功的回合。
  3. 对攻击者和智能体分别做监督微调（SFT），让它们先学会基本的成功模式。
  4. 使用 KL 正则化，避免偏离原始模型太远。

阶段 2：对抗式强化学习（核心）

采用种群训练（Population-Based Training），这是关键创新点。

训练迭代结构：

每次迭代包含：

  • 数据收集
  • 模型更新

数据收集（对抗配对策略）

  • 对智能体（Agent）：

    • 当前最新的智能体 ( \pi_{agt}^i )
    • 从所有历史攻击者 ( {\pi_{atk}^1, …, \pi_{atk}^i} ) 中均匀采样一个对手
    • 目的：让智能体见过所有旧攻击模式，防止“遗忘”

  • 对攻击者（Attacker）：

    • 当前最新的攻击者 ( \pi_{atk}^i )
    • 只和当前最新的智能体 ( \pi_{agt}^i ) 对战
    • 目的：迫使攻击者不断创新，不能只欺负旧版本

这比“最新对最新”的迭代学习更稳定，避免策略循环振荡。

模型更新（GRPO 算法）

因为奖励只出现在回合结束，需要做信用分配，ARLAS 采用 GRPO（Group Relative Policy Optimization）：

  1. 对每个任务，采集 ( G ) 个回合（如 16 个）。

  2. 对每个回合的每个动作，计算相对优势：
    [
    A_{t,j}^g = \frac{r_T^g - \text{mean}({r_T})}{\text{std}({r_T})}
    ]

    • 正优势：该回合比平均好
    • 负优势：比平均差

  3. 过滤掉优势为 0 的回合（太简单或太难，无学习价值）。

  4. 使用 裁剪的 PPO 风格目标 更新策略：

    • 计算新旧策略的概率比 ( R_{t,j}^g )
    • 裁剪到 ( [1-\epsilon_{low}, 1+\epsilon_{high}] )
    • 加上 KL 正则项，防止偏离 SFT 模型太远

阶段 3：输出最终模型

训练多轮后，返回最终的智能体模型 ( \pi_{agt} )，用于实际部署。

四、关键技术创新（方法上的亮点）

技术点 具体做法
预热（SFT） 用更强模型收集成功轨迹，解决初始探索难
种群训练 智能体对所有历史攻击者训练，避免遗忘
非对称配对 攻击者只打最新智能体，强制创新
稀疏奖励处理 GRPO 做组内归一化，过滤无用轨迹
多样性生成 攻击者被奖励驱动，自动产生多样化注入（验证了嵌入距离增大）

五、一句话总结方法

ARLAS = 模仿学习预热 + 种群对抗式 RL（智能体打所有旧攻击者，攻击者只打最新智能体）+ GRPO 优化稀疏奖励，最终生成一个既安全又能完成任务的高鲁棒性 LLM 智能体。

公式 1：优势函数（这回合表现怎么样）

At,jg=rTg−mean({rTg}g=1G)std({rTg}g=1G)

符号说明

符号 含义 人话
At,jg 第 g 个回合中，第 t 步第 j 个 token 的优势 这个回合的"得分系数"
rTg 第 g 个回合的最终奖励（只有最后一步 T 才有值） 这回合得了多少分
G 同一任务采集的回合总数 一共跑了 16 局
mean / std 对这 G 个 rT 求平均和标准差 16 局的平均分和波动

做了什么？

用同一任务的 16 个回合成绩 做归一化，算出每个回合的相对好坏。

公式 2：概率比（模型变心了多少）

Rt,jg=π(at,jg∣stg,at,<jg)πold(at,jg∣stg,at,<jg)

符号说明

符号 含义 人话
Rt,jg 第 g 回合第 t 步第 j 个 token 的概率比 “变心倍率”
π 当前模型（正在训练更新的那个） 新模型
πold 旧模型（采集这批数据时的那个） 旧模型
at,jg 第 g 回合第 t 步生成的第 j 个 token 具体的某个词
stg 第 g 回合第 t 步的状态 当时看到了什么
at,<jg 第 j 个 token 之前已经生成的所有 token 这个词前面的上下文

做了什么？

用旧模型采集的数据，但用新模型算概率，看新模型对同一个 token 的偏好变化了多少倍。

公式 3：损失函数（怎么调模型）

LRL(π)=E[1∑g=1G∑t=1T|atg|∑g=1G∑t=1T∑j=1|atg|(min(Rt,jg⋅At,jg,clip(Rt,jg,1−ϵlow,1+ϵhigh)⋅At,jg)+βRL⋅KL[π∣∣πSFT])]

符号说明

符号 含义 人话
LRL 强化学习损失函数 总损失（越小越好）
E[⋅] 对所有数据取平均 整体平均
∑g∑t∑j 遍历所有回合、所有步骤、所有 token 每个词都算一遍
1总token数 归一化分母 防止长度不同影响损失大小
$ a_{t}^{g} $
min(⋅,⋅) 取两者中较小的 保守更新
clip(R,1−ϵlow,1+ϵhigh) 把 R 限制在 [0.9,1.3] 范围内 安全绳，防止步子太大
ϵlow=0.1 下界 = 0.9 R 不能低于 0.9
ϵhigh=0.3 上界 = 1.3 R 不能高于 1.3
βRL=0.05 KL 正则化系数 控制"稳一稳"的力度
KL[π∣∣πSFT] 当前模型与 SFT 模型的 KL 散度 当前模型跑偏了多少
πSFT 模仿学习阶段结束后的模型 基准版好学生

做了什么？

把每个 token 的 R 和 A 结合起来，指导模型更新方向，同时加了两道保险：

  1. 裁剪： R 跑出 [0.9,1.3] 就拉回来
  2. KL 正则：整个模型跑偏就拽回 SFT

Q-Learning 核心公式

一、核心公式

Q(s,a)←Q(s,a)+α[r+γmaxa′Q(s′,a′)−Q(s,a)]

二、符号含义

符号 含义
Q(s,a) 在状态 s 做动作 a 的价值评分
r 做动作后立刻得到的奖励
γ 折扣因子（未来奖励的打折率，常用 0.95）
maxQ(s′,a′) 在新状态下未来能得到的最高评分
α 学习率（新信息覆盖旧信息的速度，常用 0.1）

三、一句话理解

新评分 = 旧评分 + 学习率 × (实际拿到的 + 未来预期的 - 旧评分)

终止状态 Q←Q+α[r−Q] （没有 γmaxQ(s′) ）
撞墙（状态不变） 同上， s′=s ， Q 依然更新

关于GD-UAP方法

Posted on 2026-08-06 Edited on 2026-08-17

基本原理：

深度学习模型对输入
x和扰动δ并非完全线性，但存在相关性。即
f(x+δ)−f(x) 与 f(δ)高度相关。为什么这个相关性存在？
深层网络虽不是严格的线性系统，但ReLU等激活函数在局部近似线性。因此，扰动δ本身在网络中引发的“特征响应模式”，与它叠加到真实图片x上后引发的“特征变化模式”高度一致。
换句话说：“δ的独立激活方向”就是“δ对x的破坏方向”。因此，最大化 f(δ）（即单独输入扰动时的特征响应），往往能在真实输入上产生显著的输出变化。

UAP历史发展:

早期考虑是对一组图片进行deepfool(最短距离扰动)扰动叠加，也就是对于无法欺骗的图片，用deepfool生成它的最小扰动然后加到累计的扰动上，如果已经可以欺骗，则跳过这个图片。

早期方法缺点:

需要大量数据，可能会因为叠加导致毁坏原先结构需反复验证，计算量庞大。且非完全黑盒，不切实际,以及愚弄的概念可能需要专门设计

细碎想法

很让人惊讶的一点是:即使经过打印、光照变化、角度倾斜、摄像头传感器噪声等物理失真，对抗样本依然能骗过模型。这与我之前对对抗样本这种细微扰动的直觉判断是不符合的。
这里还提到range prior的做法，按照高斯分布生成随机数据d来模拟真实的x，防止扰动脱离实际，但是随机生成的数据d本身缺乏意义性，是否会对训练有影响？

L2 范数（能量）比均值更能代表“神经元整体兴奋程度”，连乘迫使所有层都充分激活，因此 GD-UAP 更强。

算法步骤

GD-UAP 算法流程

一、输入与输出

  • 输入：目标CNN模型 f，数据载体 g（g=0 或 g=伪数据 d 或 g=真实数据 x）
  • 输出：通用扰动 δ
  • 超参数：ξ=10，η=0.1，θ=1e-5，H（耐心值）

二、算法步骤

  1. 初始化

    • 随机初始化 δ₀ ~ U[-ξ, ξ]
    • t = 0
    • F_t = 0

  2. 循环迭代（重复执行以下步骤）

    • 2.1 采样数据载体 g

      • No Prior：g = 0
      • Range Prior：g = 高斯伪数据 d（随机裁剪+增强）
      • Data Prior：g = 真实图片 x（随机采样）

    • 2.2 前向传播

      • 计算各层特征图：l₁(g+δ)，l₂(g+δ)，…，l_K(g+δ)
      • 只刺激卷积层，不碰全连接层

    • 2.3 计算损失

      • Loss = -∑ log( ∏ ||l_i(g+δ)||₂ )
      • 连乘：确保每一层都被充分激活
      • 取对数：防止数值下溢

    • 2.4 反向传播与更新

      • 计算梯度：∇_δ(Loss)
      • 梯度上升更新：δ ← δ + η · ∇_δ(Loss)
      • 限幅：δ ← clip(δ, -ξ, ξ)
      • 注意：模型权重冻结，只更新 δ

    • 2.5 自适应缩放

      • 计算饱和率 S_t（像素值 == ±ξ 的比例）
      • if S_t 增长速度 < θ：
        • δ ← δ / 2（释放空间，保留方向模式）

    • 2.6 验证

      • 每 200/400 步在验证集 D 上测试愚弄率 F_t

  3. 收敛判断

    • if F_t 连续 H 次不再提升：
      • 停止迭代

  4. 返回结果

    • j ← argmax(F_t)
    • return δ_j

三、核心损失函数

Loss = -∑ log( ∏ ||l_i(g+δ)||₂ )

  • l_i：第 i 层卷积层的输出特征图
  • ||·||₂：L2范数（该层总能量）

四、三种数据模式

模式 载体 g 说明
No Prior g = 0 纯黑背景，完全无数据
Range Prior g = d 高斯伪数据，使用数据均值和动态范围

关于3B1B的视频

矩阵是对空间线性变化的描述
行列式的数值是单位面积在该矩阵所描述空间变换下的大小

点积意味对把一个向量按照同另一个向量倒置成的1*2矩阵做线性变化。

三维的叉积是一个向量，其长度由u和v构成的平行四边形面积决定

把乘法看作行列向量点积会做的快些

一点额外的

我必须告诉你的是,(XTX)i j是X的i特征和j特征的点积.数值越大，特征i和特征j在样本上“同向变化”的趋势越强。也就是它们的线性相关性。在几何上也可以描述基向量的长度和家教。

统计学中往往行是样本，列是特征，XXT的每一个位置是样本i和样本j的点积，这个大小可以反映出样本之间的相似度，在几何上，他还可以用来计算在某个方向向量上所有列向量的投影平方和。因此 XXT 的较大特征值对应的特征向量，就是基向量集合整体延伸的主要方向。

要多关注点积在描述向量相关性方面的想法，useful
