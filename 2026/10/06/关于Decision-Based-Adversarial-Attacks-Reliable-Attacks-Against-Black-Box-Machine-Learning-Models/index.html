关于Decision_Based Adversarial Attacks_Reliable Attacks Against Black_Box Machine Learning Models

Created2026-10-06|Updated2026-10-07|论文研读

你需要一个对抗样本，然后尝试在不改变其对抗型的前提下修复它

这里的说法就可以让我注意到，所谓的对抗性应该是针对某个单独的模型的,也就是说你可能对于某个模型有对抗性，而对其他模型没有？

  1. 获取一个对抗样本,和它的原始图像
  2. 在iid高斯分布中采样(每个像素独立采样)然后投影到垂直于原始样本->对抗样本的超平面(以便最合适的靠近它)，根据步长做出移动，成功保留不成功撤回，然后再根据整体的一些结果(成功率)动态调整步长，
  • 那么，用它去修改一个对抗样本会让事情变得更好吗?
    答复:这个攻击主要应用在优化依赖决策的攻击上，可以注意到它也只依赖查询。我做了实验去思考这些问题

Decision-Based Adversarial Attacks 笔记

核心定位

提出 Boundary Attack，仅依赖模型最终决策的对抗攻击，适用于真实黑盒场景。

攻击分类

类型 所需信息 代表方法
Gradient-based 梯度 FGSM, DeepFool, C&W
Score-based 置信度分数 ZOO
Transfer-based 训练数据 + 替代模型 Papernot et al.
Decision-based 仅最终决策 Boundary Attack

Boundary Attack

核心思想

从已是对抗样本的初始点出发，沿对抗/非对抗边界随机游走，保持对抗性的同时减小扰动。

算法流程

  1. 初始化：找一个对抗样本 o~0
  2. 循环：
    • 从提议分布采样扰动 ηk
    • 若 o~k−1+ηk 仍为对抗样本，接受；否则拒绝

初始化

  • 无目标：从 U(0,255) 采样直到误分类
  • 有目标：从目标类样本出发

提议分布

  1. 从 iid 高斯分布 N(0,1) 采样
  2. 投影到垂直于“当前对抗样本 → 原图”方向的超平面
  3. 缩放到步长 δ
  4. 向原图移动一小步 ϵ

对抗准则

支持误分类、目标误分类、top-k 误分类、置信度阈值等。

超参数调整

两个参数：

参数 控制 调整依据
δ 正交扰动大小 正交扰动后仍为对抗样本的比例，目标约 50%
ϵ 向原图移动距离 向原图移动后仍为对抗样本的比例

ϵ→0 时收敛。

实验结果

无目标攻击（中位数平方 L2 距离）

攻击 MNIST CIFAR VGG-19 ResNet-50 Inception-v3
FGSM 4.2e-02 2.5e-05 1.0e-06 1.0e-06 9.7e-07
DeepFool 4.3e-03 5.8e-06 1.9e-07 7.5e-08 5.2e-08
C&W 2.2e-03 7.5e-06 5.7e-07 2.2e-07 7.6e-08

有目标攻击

攻击 MNIST CIFAR VGG-19

Boundary 6.5e-03 3.3e-05 9.9e-06

计算代价

ResNet-50 上平均：

  • DeepFool：约 7 次前向，37 次反向
  • C&W：16,000 次前向，16,000 次反向
  • Boundary：1,200,000 次前向，0 次反向

对防御的鲁棒性

防御性蒸馏使梯度攻击失败，但 Boundary Attack 仍有效：

攻击 MNIST 标准 MNIST 蒸馏 CIFAR 标准 CIFAR 蒸馏
FGSM 4.2e-02 失败 2.5e-05 失败
Boundary 3.6e-03 4.2e-03 5.6e-06 1.3e-05

结论：防御性蒸馏仅是梯度掩蔽，未真正提升鲁棒性。

真实应用

攻击 Clarifai 黑盒 API：

  • 品牌识别（500+ 品牌）
  • 名人识别（10,000+ 名人）

仅使用最终标签，不提供置信度。多数扰动在 1e−2 到 1e−3 ，肉眼几乎不可见。

贡献

  1. 强调 decision-based 攻击的重要性
  2. 提出 Boundary Attack，与梯度攻击性能相当
  3. 证明防御性蒸馏无效
  4. 成功攻击真实黑盒 API

局限

  • 计算成本高，需要大量模型查询
  • 提议分布可进一步优化

我的复现实验（2026-09-23）

目的

用 AutoAttack（AA）生成对抗样本攻击三个防御模型，再用本文的 Boundary Attack 强化这些对抗样本，然后重新攻击对比——检验**“决策式黑盒攻击能否比 AA 打得更狠”**。

设置

  • CIFAR-10 / C1Net（约 200K 参数）/ 500 测试样本 / L∞ ， ε=8/255
  • 三个目标模型：
模型 说明 clean
对抗训练 C1 PGD-4 对抗训练 65.78%
PixelDP σ=0.25 输入加高斯噪声训练（L=0.1 档） 69.67%
噪声训练 σ=0.51 更大噪声档（RS 认证半径最大档） 64.60%
  • AA 协议：确定性模型用 standard；随机化模型用 rand+EOT10（各自最严格协议）
  • 边界攻击：δ=0.01、ε=0.01 起步并动态调整；强化任务 1500 步，攻幸存者任务 4000 步
  • 所有结果用 K=50 抽样复核（随机化模型的判定本身是抽样投票）

三处方法学加固（踩过的坑）

  1. 必须排除"干净图本来就分错"的样本——否则原图本身就是对抗样本，边界攻击会走到 L2=0 的假成功（冒烟测试三个模型都报出 L2=0.0000）
  2. 随机化模型必须高抽样复核——K 小时"攻破"可能只是投票噪声（冒烟里 8 个 AA 对抗样本有 5 个复核不通过）
  3. 初始化要细粒度搜索最近起跳点——噪声尺度从 0.02 到 0.9 共十档，给边界攻击一个尽量近的起点

结果

注意：AA 的 Linf 中位数恰好是 8.0/255——攻击用满整个预算，白盒梯度攻击强度已饱和。

Round 2a：边界攻击强化（扰动最小化）

目标模型 样本数 K=50 复核通过 L2 强化前 L2 强化后 比值
对抗训练 C1 100 100 1.6949 1.2318 0.727

L2 扰动降低 27%~41%，看起来"AA 的扰动比必要的偏大"。

⚠️ 关键补测：Linf 合规性

边界攻击只最小化 L2、不约束 Linf。补测 200 样本：

目标模型 AA 扰动 Linf 中位 BA 强化后 Linf 中位 仍满足 Linf ≤ 8/255
对抗训练 C1 8.0/255 24.0/255 14.0%（7/50）
PixelDP σ=0.25 8.0/255 8.9/255 46.7%（7/15）
噪声训练 σ=0.51 8.0/255 8.1/255 47.1%（8/17）

“L2 变小"不等于"攻击更强”：在对抗训练模型上，边界攻击把扰动集中到少数像素，Linf 飙到 24/255（超预算 3 倍），仅 14% 的强化样本仍在 ε=8/255 的 Linf 球内。同一威胁模型下它并不比 AA 更强。

Round 2b：边界攻击攻击 AA 的幸存者

做法（四步）：

  1. 确定幸存者：clean_ok（干净原图预测正确，K=50 复核）且 not broken（AA 未攻破，K=50 复核）
  2. 找起跳点：边界攻击必须从"已误分类"的点出发。既然 AA 失败，手里没有近处的对抗点，只能自己造：x + N(0,s²)，按十档阶梯 s ∈ {0.02, 0.05, 0.08, 0.12, 0.18, 0.25, 0.35, 0.5, 0.7, 0.9} 取最小的能误分类的那个（K=50 复核）
  3. 跑边界攻击 4000 步（批量并行，K=10 投票判定是否仍为对抗样本）
  4. K=50 复核最终结果，统计最小 L2、落进预算（1.7442）的个数

为什么打不动——三个叠加的原因：

  1. 起跑线太远：初始 L2 中位 19~22，目标是 <1.7442，需要压缩 11~13 倍；而 4000 次查询只完成了整段路程的约 1/4（对数尺度）
  2. 查询预算只有论文的 1/300：论文实测约 120 万次查询/样本才能收敛
  3. 初始化本身就违反威胁模型：起跳用 σ 中位 0.5~0.7 的高斯噪声，其 Linf≈3σ≈1.5∼2.1 （即 380~540/255），远超 8/255 预算——Round 2b 从一开始就是在威胁模型之外起跳

额外发现（随机化防御的屏障）：PixelDP/RS 上 K=50 复核通过率极低（10/101、11/87）。因为攻击者只能看到 K=10 的投票标签，而更精确的判定会把边界附近的"成功"推翻——随机化防御的有效判定精度本身就是攻击成本的一部分。

本质局限：边界攻击是"最小化"工具（把扰动往小里压），却被用来解"最大化"问题（在鲁棒模型上找新攻击）。要攻破鲁棒样本，正确的工具是梯度类攻击（在球内最大化损失，即 AA/PGD）或更高效的决策式攻击（HopSkipJump，用二分搜索 + 蒙特卡洛估计边界梯度，查询效率高 1~2 个数量级）。

结论

  1. AA 已用满威胁模型预算：三个模型上 AA 的 Linf 中位数都恰好是 8.0/255，强度饱和，留给决策式攻击的空间很小。
  2. 边界攻击的"强化"是 L2 意义下的，会突破 Linf 约束：L2 降低 27%~41%，但 Linf 中位升到 8.1~24.0/255，仅 14%~47% 仍在原威胁模型内。报告"更小扰动"时必须同时报告范数合规性，否则结论误导。
  3. 决策式攻击打不动 AA 的幸存者：起跑线在中位 L2 19~22，4000 次查询只压到 6~11（预算 1.7442），约完成 1/4 路程。这反过来说明 AA 的鲁棒率评估在这些模型上是可靠的，不存在"AA 打不动、换决策式攻击就能破"的隐藏脆弱性。
  4. 随机化防御多了一道额外屏障：PixelDP/RS 上边界攻击结果的 K=50 复核通过率很低（10/101、11/87）——攻击者只能看到 K=10 的投票标签，更精确的判定会推翻边界附近的"成功"。随机化防御的有效判定精度本身就是攻击成本的一部分。

与本文结论的异同

  • 相同：边界攻击确实能在零梯度、零置信度条件下找到对抗样本（本文核心论点成立），且计算成本远高于梯度攻击（本文自己列出的局限）。
  • 补充：本文测试的是标准模型与防御性蒸馏模型——蒸馏只是梯度掩蔽，所以决策式攻击照样打穿（本文表格里 Boundary 在蒸馏模型上的扰动与标准模型同量级）。而本次实验用的是对抗训练/平滑训练的模型：结果是在实用查询预算内，边界攻击不比 AA 更强（R1→R2 几乎不变）。
  • 综合：这恰好从反面印证了本文的论点——能挡住决策式攻击的才是真鲁棒。梯度掩蔽只能骗过梯度攻击（对 Boundary 无效），而对抗训练/平滑训练把决策式攻击也一起防住了。
