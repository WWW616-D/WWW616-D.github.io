关于 Certified Robustness to Adversarial Examples with Differential Privacy

Created2026-10-03|Updated2026-10-04|论文研读

简单想法

  • 这里介绍了一个叫做dp(差分隐私)的概念,大概的含义是，即使你在某个输入中去掉(改动)了某些信息，你获取的输入也不会发生明显变化。通过用合适的方法添加噪声可以实现这一点。
  • 作者考虑把这个概念引进到深度学习中，在神经网络中间添加一个噪声层，同时对噪声层之前的输出做敏感度约束(各种归一化的方法)？然后去验证证明这也是一种dp
  • 这种方法的重点就是通过加噪音去创造一个安全的区间用一些测验方法求出安全区间的大小

PixelDP 笔记

一、要解决的问题

对抗样本：输入做微小扰动，模型预测错误。

现有认证防御的缺陷：

  • 无法扩展到大网络/大数据集
  • 局限于特定模型结构

PixelDP 目标：既 scalable 又通用的认证防御。

二、核心思想

把输入特征（像素）视为数据库记录，评分函数视为随机算法。

若评分函数对像素满足 (ϵ,δ) -差分隐私，则输入微小变化不会显著改变输出分布。

DP 与鲁棒性的类比：

DP 鲁棒性
数据库 输入图片
一条记录 一个像素
改一条记录 改一个像素
输出分布几乎不变 预测分布几乎不变

三、理论工具

DP 定义

对相邻数据库 d,d′ ，任意输出集合 S ：

P(A(d)∈S)≤eϵP(A(d′)∈S)+δ

Lemma 1（期望输出稳定性）

若 A 满足 (ϵ,δ) -DP，输出在 [0,b] ：

E(A(x))≤eϵE(A(x+α))+bδ

Proposition 1（鲁棒性条件）

若存在标签 k ：

E(Ak(x))>e2ϵmaxi≠kE(Ai(x))+(1+eϵ)δ

则模型对 ∥α∥p≤1 的攻击鲁棒。

群隐私

攻击大小从 1 扩展到 L ， ϵ 变为 Lϵ 。

四、PixelDP 架构

原始网络：

Q(x)=h(g(x))

改造后：

AQ(x)=h(g~(x)+Z)
  • g~ ：前置层，敏感度约束为固定值
  • Z ：Laplace 或 Gaussian 噪声
  • h ：后续层，不用改（后处理性质）

噪声量

Laplace：

σ=2Δp,1Lϵ

Gaussian：

σ=2ln⁡(1.25/δ)Δp,2Lϵ

噪声层位置

位置 敏感度
输入图像 Δ=1
第一层后 矩阵范数
自编码器 适合大模型

五、敏感度约束

线性层敏感度等于矩阵范数：

输入/输出范数 矩阵范数 约束方法
1→1 |W|1,1 列 1-范数归一化
1→2 |W|1,2 列 2-范数归一化
2→2 |W|2,2 SVD 截断奇异值
∞→∞ |W|∞,∞ 行 1-范数归一化

训练时每个 SGD 步后做投影，保持敏感度 ≤1 。

六、训练过程

每个 batch：

  1. 前向： g(x)+Z ， Z 重新采样
  2. 计算损失（单次噪声采样）
  3. 反向传播 + SGD
  4. 投影前置层权重，约束敏感度

后续层与普通训练相同。

训练时加噪声的目的：让模型在噪声下工作，增大真实标签的 margin。

七、认证预测

多次采样

对输入 x 调用 A(x) 共 n 次，估计：

E^(Ak(x))=1n∑i=1nak,i(x)

用 Hoeffding 或 Bernstein 不等式给置信区间 [E^lb,E^ub] 。

Proposition 2（广义认证条件）

若：

E^lb(Ak(x))>e2ϵmaxi≠kE^ub(Ai(x))+(1+eϵ)δ

则预测以概率 ≥η 对 p -范数 L 的攻击鲁棒。

失败概率 1−η 来自 Monte Carlo 估计，可增大采样次数减小。

认证大小

Lmax=maxLLs.t. 认证条件成立

八、关键性质

  1. 后处理性质：对 DP 输出再做计算，仍 DP。后续层不用改。
  2. 认证确定性：DP 保证本身无失败概率，失败概率只来自采样估计。
  3. 多次采样不需要组合性质：认证对象是单次 A(x) 的期望。
  4. 群隐私：攻击大小 L 对应 ϵ 放大 L 倍。

九、实验结果

数据集 模型 clean 认证精度
ImageNet Inception-v3 + 自编码器 68.3%（L=0.1） 59%（T=0.09）
CIFAR-10 ResNet 87.0%（L=0.1） 约 60%
SVHN ResNet 93.1%（L=0.1） —
MNIST CNN 99.1%（L=0.1） —

训练开销：+1.5%。

预测开销：300 次采样约 0.42s，约 42 倍。

十、与对抗训练对比

对抗训练 PixelDP
优化目标 minθmax|α|≤LL minθEZ[L] ，s.t. Δ≤1
认证 无 有
clean 下降较多 下降可控
训练开销 高 低

十一、局限

  • 对 ∞ -范数攻击认证能力弱
  • 预测需多次采样，计算开销大
  • 噪声降低 clean 精度

十二、延伸：随机平滑（Randomized Smoothing）

同样是"在输入加噪"，但把认证工具从 DP 换成 Neyman-Pearson 引理，认证半径可以大一个数量级（Cohen et al. 2019）。

平滑分类器

不认证原模型 f ，而是认证它的"加噪投票"版本：

g(x)=arg⁡maxcP(f(x+δ)=c),δ∼N(0,σ2I)

预测时对 x 撒 n 次噪声、各投一票，取票数最多的类。

证书对任意 f 都成立——不需要把噪声嵌进模型，也不需要做敏感度约束（这是相对 PixelDP 最大的工程优势：BatchNorm、残差、现成模型都能直接用）。

认证半径

R=σ2[Φ−1(pA)−Φ−1(pB)]≈σ⋅Φ−1(pAlb)
  • pA ：噪声下投给 top 类的概率（票率）
  • pAlb ：其置信下界（Clopper-Pearson 二项界）
  • 证明思路：Neyman-Pearson 给出平移下方差不变高斯的最坏情况是半空间，令"top 类最坏损失"仍大于"次优类最坏收益"即可解出 R

为什么比 PixelDP 紧

PixelDP 随机平滑
认证工具 DP 稳定性界 Neyman-Pearson 引理
条件形状 margin>e2ϵ⋅second+(1+eϵ)δ R=σΦ−1(pA)
形状代价 指数 e2ϵ + 固定门槛（ δ=0.05 时 ≈0.13 ） 只有 Φ−1 ，无 δ 项
根源 约束任意可测集合的概率比（乘性、通用） 只约束决策区域的票率（针对性、界可达）

用通用工具（DP）做特定任务（决策区域稳定性）必然付形状损失；随机平滑问的是同一问题的精确版本，所以半径大一个数量级。

底层几何

pc(x)=(1[z∈Rc]∗μ)(x)

平滑后的票率是"决策区域指示函数"与"噪声核"的卷积 → 攻击 = 平移核 → 票率变化的最大值由 Neyman-Pearson 精确给出。其中 Φ 的来源是高斯等周现象：“半空间在平移下变化最大”（NP）与"半空间对高斯最紧凑"（高斯等周不等式）是同一个数学事实。

训练

高斯数据增强，其余照常：

与 PixelDP 的训练本质相同（都是"加噪 + 普通 CE"），区别只在认证阶段：

阶段 PixelDP 随机平滑
训练 加噪 + CE 加噪 + CE（一样）
预测聚合 概率向量求平均 → argmax 数硬票 → 多数
置信界 Hoeffding（对 K 类 union bound） Clopper-Pearson 二项界
认证公式 DP 稳定性界 R=σΦ−1(pA)

局限

  • 推理成本更高：每张图需 104∼105 次抽样（PixelDP 约几百次），成本从训练搬到推理
  • 只认证 L2 （认证 L1/L∞ 需重新设计噪声分布与认证函数）
  • 同样存在 σ 权衡： σ↑ → 半径 ↑ 、clean ↓
  • pA 必须估得极准（ Φ−1 在高票率处很陡），否则统计税吃掉半径

实测对照（同一批权重、同一批抽样）

实验设计：PixelDP 的训练本身就是"输入加噪 + 普通 CE"，与随机平滑的训练完全相同。所以直接复用 PixelDP 训好的权重，在同一批抽样数据上同时计算两种证书——唯一变量就是认证数学（ e2ϵ vs Φ−1 ）。

模型 C1Net（约 200K 参数），500 个测试样本，每样本 10,000 次抽样。

σ （训练=认证） 投票干净准确率 随机平滑 平均半径 PixelDP 平均半径 倍数

0.2537 72.60% 0.4641 0.0694 6.7×
0.5075 64.60% 0.5148 0.0764 6.7×

结论：同样的模型、同样的噪声、同样的抽样，只换认证公式，半径差 6.7~7.4 倍。而且 PixelDP 的界在 T≥0.2 后直接归零——模型本来就有那个安全区，只是被松界埋没了。

两个值得注意的现象：

  1. 投票比单次加噪推断更准：σ=0.5075 单次加噪推断只有 56.8%，投票后回到 64.6%——聚合真的在"去噪"。
  2. 边际收益递减：σ 从 0.25 翻倍到 0.5，平均半径几乎没动（0.464 → 0.515），clean 却掉了 8pp。继续加噪声不划算。

对照（同架构、同 ε=8/255 威胁模型）：C1 无防御基线 clean 85.29%、AA 0%；对抗训练 clean 65.78%、AA-rand 26.60%。

注：认证半径是 L2 范数（像素范围 [0,1]）。我们的攻击预算是 ε=8/255 的 L∞ ，换算成 L2 约 1.74，所以即使随机平滑的 0.46 也只覆盖了约 1/4；真正面对该攻击强度时靠的是实测鲁棒率（AA-rand 36~46%）。

十三、核心理解：两者的共性与区别

  • 这类方法（PixelDP、随机平滑）的重点都一样：在输入上加噪声，人为造出一个安全区间，再用统计方法（多次抽样 + 置信界）求出这个区间的大小，作为预测的鲁棒性证书。

  • 证书有两个共同性质：

    • 逐样本——每个输入有自己的半径，半径取决于模型在该点有多"有信心"（PixelDP 看平均概率的 margin，随机平滑看票率 pA ），换个输入半径就不同；论文正是用"认证准确率-半径曲线"来报告结果的。
    • 与攻击实现无关——只要扰动范数不超过半径，任何攻击（包括还没发明出来的）都改不了预测。这是它和"实测鲁棒率"的根本区别：实测会被更强的攻击推翻，证书不会。

  • 两者都不对"某一次前向"负责，而是对加噪后的统计量负责：PixelDP 看平均概率向量（谁是期望意义上的第一名），随机平滑看票率（多大比例投给同一类）。

  • 两者的真正区别有两处：

    1. 统一不等式的形状不同——两者都建立在一条"对任意输入成立"的不等式上（PixelDP 是 DP 的稳定性不等式，随机平滑是 Neyman-Pearson 的平移界），但 PixelDP 的界带着 e2ϵ 的指数代价外加 (1+eϵ)δ 的固定门槛，比较松；随机平滑只用 Φ−1 ，界是紧的。同样条件下认证半径差一个数量级。

    2. 噪声量由谁决定——PixelDP 的噪声必须覆盖所有输入的最坏敏感度 Δp,q ，所以被迫保守，而且模型结构受限（不能有跨噪声层的 skip connection、BatchNorm 难处理、要去掉图像标准化）；随机平滑的噪声和扰动在同一空间，"放大倍数"恒为 1，不存在最坏情况要覆盖， σ 可以自由选，因此任何模型都能直接套（哪怕 f 是间断的）。

十四、一句话总结

给网络中间加噪声层，使评分函数对像素满足 DP，用 DP 不等式证明期望输出稳定，从而对每个预测发鲁棒性证书。

随机平滑是它的"紧界版本"：同样在输入加噪，但认证改用 Neyman-Pearson 引理，把 e2ϵ 换成 Φ−1 、去掉 δ 固定门槛，认证半径因此大一个数量级——代价是推理要抽样上万次。
