关于 Transferability in Machine Learning from Phenomena to Black-Box Attacks using Adversarial Samples

Created2026-10-02|Updated2026-10-02|论文研读

这是一篇涉及比较广阔的迁移性黑盒攻击的文章，主要研究了各种机器学习模型和一些基础的深度学习模型之间的互相迁移情况，发现即使是不同技术之间也会存在迁移性。文中提到的替代模型训练主要通过查询目标模型获得，这里提到了一个可以提高查询效率的办法，每一轮增强时，先保留当前所有已标注样本，训练替代模型；然后用替代模型的 Jacobian 对部分样本（由蓄水池采样选出）生成扰动样本；再把这些扰动样本拿去查询 oracle 获取标签；最后把新标签样本加入训练集，进入下一轮。

论文笔记：Transferability in Machine Learning

标题：Transferability in Machine Learning: from Phenomena to Black-Box Attacks using Adversarial Samples

作者：Nicolas Papernot, Patrick McDaniel (Penn State), Ian Goodfellow (OpenAI)

一、核心问题

对抗样本具有迁移性：为模型 f 生成的对抗样本，往往也能欺骗模型 f′ ，即使两者架构或训练集不同。

利用迁移性 → 黑盒攻击：攻击者不需要知道目标模型的架构、参数或训练数据，只需能查询它的输出标签。

二、两个核心假设

假设 内容 验证
假设 1 同技术和跨技术迁移性在整个 ML 空间中都持续强 第 3 节
假设 2 黑盒攻击在实际场景中对任何未知 ML 分类器都可行 第 4、5 节

三、两种迁移性

类型 定义 举例
同技术迁移 同一算法训练的不同模型之间 DNN → DNN
跨技术迁移 不同算法训练的模型之间 LR → SVM

主要发现

  • 同技术迁移：LR 最脆弱（>94%），DNN 次之（≥49%），SVM/DT/kNN 更鲁棒但仍存在迁移。
  • 跨技术迁移：DT 最脆弱（47.20%–89.29%），DNN 最鲁棒（0.82%–38.27%）。
  • Ensemble 也不安全：LR 的对抗样本能让集成模型 44.14% 误分类。

四、替代模型学习

基础方法：Jacobian-based 数据增强

Sρ+1={x→+λρ⋅sgn(Jf[O~(x→)]):x→∈Sρ}∪Sρ
  • Jf ：替代模型的 Jacobian
  • O~(x→) ：oracle 标签
  • 迭代增强 + 重新训练

两项改进

改进 作用 关键参数
周期步长（PSS） 步长正负交替，提升精度 τ=3
蓄水池采样（RS） 每轮只选 κ 个样本增强，降低查询 σ=3,κ=400

查询次数对比

  • Vanilla： n⋅2ρ=102,400
  • PSS + RS： n⋅2σ+κ⋅(ρ−σ)=3,600

减少约 28 倍。

替代模型类型对比

替代模型 对 DNN oracle 对 LR oracle 对 SVM oracle 对 DT oracle 对 kNN oracle
DNN + PSS 89.28% 89.16% 83.79% 61.10% 85.67%
LR + PSS 69.20% 84.01% 82.19% 34.14% 71.02%
SVM 11.98% 11.97% 79.80% — —
  • DNN 和 LR 是好的替代模型；
  • SVM 只能逼近 SVM，无法跨技术迁移。

五、商业平台攻击

平台 替代模型 查询次数 误分类率
Amazon ML LR 800 96.19%
Amazon ML DNN + PSS + RS 2,000 95.68%
Google Cloud LR 800 88.94%
Google Cloud LR + PSS + RS 2,000 97.72%
  • Amazon 模型推测为多项式逻辑回归；
  • Google 模型类型未知，但依然脆弱；
  • 对抗训练防御无效。

六、对抗样本生成方法

模型 方法 特点
DNN / LR / kNN Fast Gradient Sign Method 基于梯度
SVM 超平面正交扰动 无需优化，本文首次提出
DT 叶子路径搜索 无需梯度，本文首次提出

七、主要贡献

  1. 将迁移性研究从 DNN 推广到整个 ML 空间（LR、SVM、DT、kNN、Ensemble）；
  2. 首次提出 SVM 和决策树的对抗样本生成方法；
  3. 引入周期步长和蓄水池采样，提升替代模型精度、降低查询成本；
  4. 攻击 Amazon 和 Google 商业平台，仅 800 次查询达到高误分类率；
  5. 证明对抗训练防御在浅层模型上无效。

八、一句话总结

对抗样本的迁移性普遍存在于整个机器学习空间，攻击者可以用少量查询训练替代模型，对替代模型生成对抗样本，再迁移到黑盒目标模型，实现高效攻击。

九、后续研究补充

  • 替代 DNN 的具体架构对迁移性影响有限；
  • 非目标攻击容易迁移，目标攻击很难迁移；
  • 迁移性根源：模型学到相似的非鲁棒特征；
  • 经验阈值：ε < 0.1 几乎无效，ε = 0.2 约 50%，ε = 0.3 稳定高效。
