实验总结:梯度遮蔽与对抗防御在AutoAttack面前的表现差异

Created2026-09-23|Updated2026-09-23
  • 我在今天完成了如标题所展示的实验,实验结果大概是梯度遮蔽方法在AutoAttack面前具有相当的脆弱性，只在针对梯度的攻击下表现良好。
  • 需要考虑防御蒸馏方法中温度T的设置，如果在教师模型中设置过高的温度可能会与权重缩减产生不良反应，本次实验采用的是论文的标准做法，在教师模型中不设置T而在学生模型中设置T=20。使得决策边界更加的平滑。
  • 后续采用了PGD方法生成对抗样本对Base模型进行调整，但是正常情况下的正确率有较大下滑，在Autoattack攻击下展现了一定的抵抗率，需要注意是PGD步数在对抗训练中适当减少有助于提升正确情况下的正确率，应该是可以减少对对抗样本的过度拟合。
  • 更大的模型有更好的效果，这是理所当然的事情

下面是AI制作的关于实验环境配置与各项参数与数据的总结

实验环境

  • 设备：Windows 本地 CPU（16 线程），无 GPU
  • 框架：PyTorch 2.11.0 (CPU)，Python 3.13
  • 数据集：CIFAR-10（50000 训练 / 10000 测试）
  • 攻击标准：AutoAttack standard（Linf，ε=8/255，1000 测试样本）

实验一：梯度遮蔽 vs 防御蒸馏（防御实验）

模型与训练参数：LeNet（62K 参数），40 epochs，lr=0.1，SGD+momentum 0.9，CosineAnnealing。
防御蒸馏采用论文标准做法：教师 T=1 正常训练，学生 T=20 高温软标签（lr=4.0，wd=0）。

攻击配置：AutoAttack（APGD-CE/DLR + FAB + Square）、PGD-20 白盒、BPDA-PGD-20（自适应，拆穿梯度遮蔽）、迁移攻击。

结果（robust acc = 越小越不安全）：

模型 clean% AA% PGD20% BPDA% transfer%
baseline（无防御） 71.39 0.00 0.00 — 0.00
distill（防御蒸馏 T=20） 68.83 0.10 0.10 — 36.30
mask_sat（饱和输出梯度遮蔽） 68.42 0.10 0.20 1.40 50.50
mask_prep（位深缩减梯度遮蔽） 68.85 5.60 67.90 0.60 44.40

关键发现：

  • 梯度遮蔽对基于梯度的攻击（PGD）表现良好（如 mask_prep PGD20=67.90%），但在 AutoAttack 的免梯度 Square 攻击（AA=5.6%）和自适应 BPDA 攻击（0.6%）下迅速失效——是"假防御"，只是骗过了梯度攻击。
  • 防御蒸馏在 AA 下基本失效（0.1%），只能提升迁移攻击抵抗（36.3% vs baseline 0%），符合 Carlini & Wagner (2017) 的结论。

实验二：对抗训练（LeNet 62K）

方法：标准对抗训练（Madry et al. 2018），从头随机初始化，每 batch 用 PGD 实时生成对抗样本加入训练。

配置 clean% AA% PGD20%
PGD-7, 30 epochs 46.33 22.90 28.70
PGD-4, 60 epochs 50.96 22.50 27.30

关键发现：

  • 对抗训练把 AA 从 baseline 的 0% 提到 ~22-23%，是第一个真正有效的防御。
  • PGD 从 7 降到 4，clean 从 46.33% 提到 50.96%（+4.6%），而 AA 基本持平（22.9→22.5）。原因：训练攻击越弱，模型越不用牺牲干净性能去死磕最难的对抗样本，减少了对对抗样本的过度拟合。
  • 尝试从已收敛 baseline 直接微调会崩溃（clean 从 71% 掉到 10%）：对抗损失是干净损失的 13.8 倍、对抗样本 100% 击穿脆弱模型。因此采用从头训练。

实验三：对抗训练 + 更大模型（C1Net，200K 参数）

动机：62K 的 LeNet 容量不足，clean 上不去（50.96%），认为这是根本瓶颈。

C1Net 架构：4 卷积层（3→32→32→64→64，3×3）+ 3 全连接（256→256→10），约 200K 参数，无 BN/残差。

训练参数：PGD-4，60 epochs，lr=0.1，ε=8/255，α=2/255。

结果：

配置 参数 clean% AA% PGD20%
LeNet + PGD-7 62K 46.33 22.90 28.70
LeNet + PGD-4 62K 50.96 22.50 27.30
C1 + PGD-4 200K 65.78 26.80 31.70

关键发现：

  • 加大模型容量后，clean 从 50.96% 提到 65.78%（+15%），同时 AA 从 22.5% 提到 26.8%（+4.3%）——打破了"clean 涨鲁棒必跌"的权衡，因为瓶颈是容量不足，而非强度设置。
  • C1 的 clean 65.78% 已接近无防御 baseline（71.39%），却拿到了 26.8% 的 AA 鲁棒率（baseline 为 0%）——以极小 clean 代价换取巨大真实鲁棒，是对抗训练的较理想结果。

总结

  1. 梯度遮蔽是假防御：对梯度攻击有效，但对免梯度/自适应攻击（AutoAttack 的 Square、BPDA）立刻失效。
  2. 防御蒸馏在 AA 面前失效：只能提升迁移抵抗，无法抵御白盒自适应攻击。
  3. 对抗训练是真正有效的防御：AA 鲁棒率远高于所有遮蔽/蒸馏类防御。
  4. 训练 PGD 步数越小，clean 越高：弱攻击减少对对抗样本的过度拟合（46→51%）。
  5. 模型容量是 clean 提升的根本因素：200K 的 C1 比 62K 的 LeNet 同时提升 clean 和鲁棒（51→66%）。
