实验总结:梯度遮蔽与对抗防御在AutoAttack面前的表现差异

Created2026-09-23|Updated2026-10-06|散记
  • 我在今天完成了如标题所展示的实验,实验结果大概是梯度遮蔽方法在AutoAttack面前具有相当的脆弱性，只在针对梯度的攻击下表现良好。
  • 需要考虑防御蒸馏方法中温度T的设置，如果在教师模型中设置过高的温度可能会与权重缩减产生不良反应，本次实验采用的是论文的标准做法，在教师模型中不设置T而在学生模型中设置T=20。使得决策边界更加的平滑。
  • 后续采用了PGD方法生成对抗样本对Base模型进行调整，但是正常情况下的正确率有较大下滑，在Autoattack攻击下展现了一定的抵抗率，需要注意是PGD步数在对抗训练中适当减少有助于提升正确情况下的正确率，应该是可以减少对对抗样本的过度拟合。
  • 更大的模型有更好的效果，这是理所当然的事情

下面是AI制作的关于实验环境配置与各项参数与数据的总结

实验环境

  • 设备：Windows 本地 CPU（16 线程），无 GPU
  • 框架：PyTorch 2.11.0 (CPU)，Python 3.13
  • 数据集：CIFAR-10（50000 训练 / 10000 测试）
  • 攻击标准：AutoAttack standard（Linf，ε=8/255，1000 测试样本）

实验一：梯度遮蔽 vs 防御蒸馏（防御实验）

模型与训练参数：LeNet（62K 参数），40 epochs，lr=0.1，SGD+momentum 0.9，CosineAnnealing。
防御蒸馏采用论文标准做法：教师 T=1 正常训练，学生 T=20 高温软标签（lr=4.0，wd=0）。

攻击配置：AutoAttack（APGD-CE/DLR + FAB + Square）、PGD-20 白盒、BPDA-PGD-20（自适应，拆穿梯度遮蔽）、迁移攻击。

结果（robust acc = 越小越不安全）：

模型 clean% AA% PGD20% BPDA% transfer%
baseline（无防御） 71.39 0.00 0.00 — 0.00
distill（防御蒸馏 T=20） 68.83 0.10 0.10 — 36.30
mask_sat（饱和输出梯度遮蔽） 68.42 0.10 0.20 1.40 50.50
mask_prep（位深缩减梯度遮蔽） 68.85 5.60 67.90 0.60 44.40

关键发现：

  • 梯度遮蔽对基于梯度的攻击（PGD）表现良好（如 mask_prep PGD20=67.90%），但在 AutoAttack 的免梯度 Square 攻击（AA=5.6%）和自适应 BPDA 攻击（0.6%）下迅速失效——是"假防御"，只是骗过了梯度攻击。
  • 防御蒸馏在 AA 下基本失效（0.1%），只能提升迁移攻击抵抗（36.3% vs baseline 0%），符合 Carlini & Wagner (2017) 的结论。

实验二：对抗训练（LeNet 62K）

方法：标准对抗训练（Madry et al. 2018），从头随机初始化，每 batch 用 PGD 实时生成对抗样本加入训练。

配置 clean% AA% PGD20%
PGD-7, 30 epochs 46.33 22.90 28.70
PGD-4, 60 epochs 50.96 22.50 27.30

关键发现：

  • 对抗训练把 AA 从 baseline 的 0% 提到 ~22-23%，是第一个真正有效的防御。
  • PGD 从 7 降到 4，clean 从 46.33% 提到 50.96%（+4.6%），而 AA 基本持平（22.9→22.5）。原因：训练攻击越弱，模型越不用牺牲干净性能去死磕最难的对抗样本，减少了对对抗样本的过度拟合。
  • 尝试从已收敛 baseline 直接微调会崩溃（clean 从 71% 掉到 10%）：对抗损失是干净损失的 13.8 倍、对抗样本 100% 击穿脆弱模型。因此采用从头训练。

实验三：对抗训练 + 更大模型（C1Net，200K 参数）

动机：62K 的 LeNet 容量不足，clean 上不去（50.96%），认为这是根本瓶颈。

C1Net 架构：4 卷积层（3→32→32→64→64，3×3）+ 3 全连接（256→256→10），约 200K 参数，无 BN/残差。

训练参数：PGD-4，60 epochs，lr=0.1，ε=8/255，α=2/255。

结果：

配置 参数 clean% AA% PGD20%
LeNet + PGD-7 62K 46.33 22.90 28.70
LeNet + PGD-4 62K 50.96 22.50 27.30
C1 + PGD-4 200K 65.78 26.80 31.70

关键发现：

  • 加大模型容量后，clean 从 50.96% 提到 65.78%（+15%），同时 AA 从 22.5% 提到 26.8%（+4.3%）——打破了"clean 涨鲁棒必跌"的权衡，因为瓶颈是容量不足，而非强度设置。
  • C1 的 clean 65.78% 已接近无防御 baseline（71.39%），却拿到了 26.8% 的 AA 鲁棒率（baseline 为 0%）——以极小 clean 代价换取巨大真实鲁棒，是对抗训练的较理想结果。

实验四：输入扩散变换防御（像素向八格扩散）

动机：受"视觉补齐"启发，假设对输入做"每个像素按比例向周围八格扩散"的变换，并在训练与推理时保持一致，看对抗扰动是否会被平滑/吸收进扩散分布而"被免疫"。

方法：把扩散变换包在 C1Net 外层（DiffuseNet）。三种模式，均用 3×3 核实现"新值=(1-p)·自身 + p·(8邻居均值)"，能量守恒：

模式 扩散比例 p 说明
fixed 固定 1% 每个像素固定
spatial 0~1% 随机 每个像素位置随机
global 0~1% 随机 整张图每次随机

训练：C1Net（200K 参数），普通交叉熵训练（非对抗），60 epochs，lr=0.1。训练与推理用同一变换。评估：AutoAttack + PGD-20。

结果：

模式 clean% AA% PGD20%
fixed（固定扩散） 85.06 0.00 0.00
spatial（空间随机） 85.49 0.00 0.00
global（全局随机） 85.18 0.00 0.00
—— 对抗训练（对照）—— 65.78 26.80 31.70

关键发现：

  • 扩散变换的 clean 反而最高（85%）：1% 扩散几乎不损失信息，甚至带点正则化效果，比普通训练还好。
  • 但防御力为零：无论固定还是随机，AA 和 PGD 全部 0%。随机化（spatial/global）没有提供任何额外防御。
  • AutoAttack 明确识别出随机化防御（“randomized defense! Please use version=‘rand’”），即若用带 EOT（期望梯度）的 rand 版本会打得更狠——随机性被"对多次随机变换取梯度平均"抵消。
  • PGD 也无法免疫的原因：扩散可微，PGD 直接对"扩散+模型"复合函数求梯度，攻击方向不受影响（梯度只乘个 ≈0.99 的系数），攻击者总能追得上"抹平"。

实验五：与 Madry 论文（Towards Deep Learning Models Resistant to Adversarial Attacks）的对比

论文关键配置（来自《Towards Deep Learning Models Resistant to Adversarial Attacks》, Madry et al. 2018）：

  • CIFAR-10 使用 ResNet 宽体架构：5 个残差单元，通道数为 (16, 160, 320, 640)，比标准 ResNet 加宽 10 倍。
  • 自然训练准确率 95.2%。
  • PGD 对抗训练（L∞，ε=8），数据增强用随机裁剪+翻转+每图标准化。

参数量对比：

Madry（Wide ResNet） 我的 C1 我的 LeNet
架构 ResNet 宽体，通道到 640 4 层卷积，通道到 64 2 层卷积，通道到 16
参数量 约 55M 0.2M 0.06M
PGD 对抗训练 clean 87.3% 65.78% 50.96%
PGD-20 鲁棒 45.8% 31.70% 27.30%

关键结论：

  • Madry 的模型比我大了约 270 倍（55M vs 0.2M），比我的 LeNet 大近 900 倍。这正是他们能达到 clean 87%、鲁棒 46% 的核心原因。
  • 论文原文明确指出（第 399-404 行）：“In the case of small capacity networks, attempting to train against a strong adversary (PGD) prevents the network from learning anything meaningful.”（小容量网络用强对抗训练会学不出东西）——这与我在 LeNet 62K 上遇到的"clean 卡在 46-51%、换 C1 200K 才升到 66%"完全吻合。
  • 我的实验已在同一条规律上验证：模型容量越大，对抗训练的 clean 和鲁棒同时越高（46→51→66%）。与 Madry 的差距主要来自模型小了 270 倍，而非方法本身有误。

实验六：PixelDP（基于差分隐私的认证鲁棒性）

论文：Certified Robustness to Adversarial Examples with Differential Privacy (Lecuyer et al., IEEE S&P 2019)

核心思想：把输入图像的每个像素看作数据库中的一条"记录"，在输入端加入 DP 噪声（Gaussian/Laplace 机制），使整个网络成为 (ε, δ)-PixelDP。由 DP 的后处理性质把保证传递到输出，再用 Proposition 2 的稳定性界，对每个样本解出可认证的鲁棒半径 L_max——只要攻击的 p-范数 ≤ L_max，任何攻击实现方式都无法改变预测。这是与前面所有"实测型"防御的本质区别：它给的是可证明的保证，不是"扛住了多少攻击"。

方法配置（忠实复现论文）：

  • 噪声位置：输入像素（g=identity，敏感度 Δ=1，2-范数）
  • Gaussian 机制：σ = √(2 ln(1.25/δ)) · L / ε，取 (ε=1.0, δ=0.05)（论文参数）
  • 训练：每次前向都加噪，普通 CE 损失；60 epochs，lr=0.1
  • 预测：500 次加噪取蒙特卡洛均值估计 E(A(x))，用 Hoeffding 界做置信区间（α=0.01），再解出每样本 L_max
  • 模型：C1Net（200K 参数）
  • 攻击评估：EOT-PGD-20（梯度对 10 次抽样取平均）、AutoAttack，以及管控噪声的"标准"协议

结果：

配置 σ clean% MC准确率 平均认证半径 认证@T=0.02 认证@T=0.05 认证@T=0.1 EOT-PGD AA-rand(EOT10) AA-rand(EOT20) AA-std
C1 基线（无噪） 0 85.29 — — — — — 0.00 — — 0.00
PixelDP L=0.03 0.076 79.78 82.30 0.0224 56.40 0.00 0.00 1.52 7.00 — 8.44
PixelDP L=0.1 0.254 69.67 73.80 0.0496 55.30 42.90 19.30 24.20 40.40 36.36 49.64
对抗训练 C1（对照） — 65.78 — — — — — — 26.60 — 26.40

关键发现：

  1. 噪声-准确率权衡（对应论文 Table III）：无噪 C1 基线 85.29% → L=0.03 时 79.78% → L=0.1 时 69.67%。噪声越大，认证半径越大（0.0224 → 0.0496），但 clean 越低。
  2. PixelDP L=0.1 在 EOT-AA 下鲁棒率 36.36%，高于对抗训练的 26.60%，且 clean 更高（69.67% vs 65.78%），同时还附带认证保证——这是本次研究中唯一"既有可证明保证、又实测鲁棒"的防御。
  3. 认证半径的量级远小于威胁模型：我们的 ε=8/255 Linf 攻击换算成 L2 约 1.74，而认证半径仅 ~0.05（差约 35 倍）——证书覆盖不到该攻击强度，所以轻噪声档（L=0.03）在 EOT-PGD 下只剩 1.52%。
  4. 评估协议极其关键：同一模型 AA-rand(EOT) 36.36% vs AA-standard 49.64%，后者不含 EOT，梯度攻击被输入噪声削弱而虚高 13 个百分点。评价随机化防御必须用带 EOT 的协议。
  5. 与论文对比：论文用 36M 参数的 ResNet-28-10，L=0.1 时 clean 87.0%、认证准确率 60%@T=0.1；我们 200K 的模型只有 69.67% / 19.3%——再次印证模型容量是认证鲁棒性的关键瓶颈。
  6. 附带结论：补测的 C1 无噪基线 clean 85.29%，与实验四的三种扩散变体（85.06/85.49/85.18）几乎一致，证实扩散变换对 clean 的提升贡献≈0，那 85% 完全来自更大的模型。

实验八：决策式攻击（Boundary Attack）能否比 AutoAttack 更强

论文：Decision-Based Adversarial Attacks: Reliable Attacks Against Black-Box ML Models（Brendel et al., ICLR 2018）

方法：决策式黑盒攻击，只用最终标签。从已有对抗样本出发，沿决策边界随机游走（正交随机步 δ·d + 朝原图步 ε·d），逐步最小化 L2 距离。论文实测需约 120 万次查询收敛。

流程：Round 1 用 AutoAttack 攻击三个防御模型 → Round 2a 用边界攻击强化 AA 的对抗样本 → Round 2b 用边界攻击攻 AA 的幸存者。

配置：500 样本，L∞ ε=8/255；确定性模型用 AA-standard，随机化模型用 AA-rand+EOT10；边界攻击 1500 步（强化）/ 4000 步（攻幸存者）；结果均用 K=50 抽样复核。

结果：

目标模型 R1（AA） AA 扰动 Linf 中位 强化后 L2 比 强化后仍在 Linf 预算内 R2（AA+BA）
对抗训练 C1 26.40% 8.0/255 0.727 14.0% 26.40%
PixelDP σ=0.25 47.40% 8.0/255 0.721 46.7% 47.40%
噪声训练 σ=0.51 46.40% 8.0/255 0.594 47.1% 46.20%

关键发现：

  1. AA 的 Linf 中位数恰好是 8.0/255——攻击用满整个预算，强度饱和。
  2. 边界攻击的"强化"是 L2 意义下的，会突破 Linf 约束：L2 降低 27%~41%，但 Linf 中位升到 8.1~24.0/255，仅 14%~47% 仍在原威胁模型内（对抗训练模型上飙到 24/255）。只报"扰动变小"会误导，必须同时报范数合规性。
  3. 决策式攻击打不动 AA 幸存者：4000 次查询只把距离压到 6.2~11.2（预算 1.7442），R1→R2 几乎无变化。说明 AA 的鲁棒率评估是可靠的，不存在隐藏脆弱性。
  4. 随机化防御多一道屏障：PixelDP/RS 上边界攻击结果的 K=50 复核通过率很低（10/101、11/87）——攻击者只能看 K=10 投票标签，更精确的判定会推翻边界附近的"成功"。

总结

  1. 梯度遮蔽是假防御：对梯度攻击有效，但对免梯度/自适应攻击（AutoAttack 的 Square、BPDA）立刻失效。
  2. 防御蒸馏在 AA 面前失效：只能提升迁移抵抗，无法抵御白盒自适应攻击。
  3. 对抗训练是真正有效的防御：AA 鲁棒率远高于所有遮蔽/蒸馏类防御。
  4. 训练 PGD 步数越小，clean 越高：弱攻击减少对对抗样本的过度拟合（46→51%）。
  5. 模型容量是 clean 提升的根本因素：200K 的 C1 比 62K 的 LeNet 同时提升 clean 和鲁棒（51→66%）。
  6. 输入变换（扩散）不是真防御：clean 虽高（85%）但 AA/PGD 全为 0%，随机化也救不了——白盒攻击可微变换或期望梯度绕过。
  7. PixelDP 是唯一给出"可证明保证"的防御：认证半径 0.05（L=0.1 档）、EOT-AA 下 36.4% 鲁棒且 clean 69.7%，双指标均优于同架构的对抗训练；但认证半径比 ε=8/255 威胁模型小约 35 倍，覆盖不到该攻击强度。
  8. 随机平滑是 PixelDP 的"紧界版本"：同一批权重、同一批抽样，只把认证公式从 e2ϵ 换成 Φ−1 ，平均半径从 0.069 涨到 0.464（6.7 倍），且 PixelDP 的界在 T≥0.2 后直接归零——模型本来有那个安全区，被松界埋没了。
  9. 决策式攻击不比 AutoAttack 更强：边界攻击能把 L2 扰动降低 27%~41%，但只优化 L2 不约束 Linf，强化样本仅 14%~47% 仍在 ε=8/255 内；且在 4000 次查询预算内无法攻破 AA 的任何幸存者（R1→R2 基本不变）。“扰动更小"≠"攻击更强”，必须核对范数合规性。
