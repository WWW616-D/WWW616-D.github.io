我的AI安全攻防基础笔记

Created2026-09-09|Updated2026-09-09

由FGSM衍生出发

核心概念：FGSM (Fast Gradient Sign Method)

  • 提出者：Goodfellow 等人 (ICLR 2015)
  • 核心思想：神经网络在高维空间中是线性的。沿着梯度上升的方向（使损失增大）迈出一大步，就能让模型分类错误。
  • 公式：( x^{adv} = x + \epsilon \cdot sign(\nabla_x J(\theta, x, y)) )
  • 特点：极快（仅需一次梯度计算），但成功率较低，且生成的扰动较大（噪声明显）。

第一分支：迭代法（把大步变成小步）

针对 FGSM 一次迈步太大、容易“走偏”的问题，衍生出了迭代方法。

方法 全称 核心逻辑 与 FGSM 的区别
BIM Basic Iterative Method 将 ( \epsilon ) 拆成多步 ( \alpha )，每步计算梯度并前进，始终从原始样本出发。 攻击成功率更高，但计算量增加。
I-FGSM Iterative FGSM 本质与 BIM 相同（常被混用），是“迭代版 FGSM”的通用称呼。 通过多次小步攻击，效果更精准。
PGD Projected Gradient Descent 与 BIM 流程一致，但起点不是原始样本，而是在原始样本的 ( \epsilon ) 邻域内随机选取一个起点。 增加了随机性，是目前公认的最强一阶攻击，也是对抗训练的标准对手。

第二分支：优化法（追求最小扰动）

这类方法不再盲目增加噪声，而是追求“以最小的改动骗过模型”。

方法 全称 核心逻辑 与 FGSM 的区别
DeepFoolAbout-DeepFool-a-simple-and-accurate-method-to-fool-deep-neural-networks - 迭代地将样本向最近的分类决策边界推动，直到越过边界。 扰动比 FGSM 更小，能计算出更紧致的扰动下限。
C&W Carlini & Wagner 将攻击视为一个优化问题，通过改进损失函数，确保模型以高置信度错分。 这是 FGSM 家族中攻击力最强的方法，成功攻破了防御蒸馏。

第三分支：物理世界与高级应用

方法 核心逻辑 应用场景
物理世界攻击 允许对抗样本经过打印、拍摄等物理变换后依然有效。 攻击人脸识别门禁、自动驾驶路牌识别。
Universal Perturbations 寻找一个通用的扰动向量，可以加到任何图片上，使大部分图片都被错分。 这是一种“万能钥匙”式的攻击。
