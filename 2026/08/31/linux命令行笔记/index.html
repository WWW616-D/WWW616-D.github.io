Created2026-08-31|Updated2026-09-04

一、基础命令

命令 作用 示例
pwd 显示当前路径 pwd
ls 列出文件 ls -la
cd 切换目录 cd /home/user
mkdir 创建目录 mkdir -p a/b/c
rmdir 删除空目录 rmdir dir
touch 创建空文件 touch a.txt
cp 复制 cp a.txt b.txt
mv 移动/重命名 mv a.txt b.txt
rm 删除 rm -rf dir
cat 查看文件 cat a.txt
find 查找文件 find . -name "*.c"
grep 文本搜索 grep "error" log.txt

⚠️ rm -rf 很危险，删除前先确认路径

八、实用快捷键

快捷键 作用
Tab 自动补全
Ctrl+C 终止当前命令
Ctrl+Z 挂起当前命令
Ctrl+L 清屏
↑/↓ 历史命令
Ctrl+R 搜索历史命令

九、GDB 调试（C 程序）

命令 简写 作用
break 行号 b 打断点
run r 运行
next n 单步（不进入函数）
step s 单步（进入函数）
print 变量 p 查看变量
continue c 继续运行
list l 查看源码
quit q 退出

查看内存

格式：x/数量格式 地址，格式 x=十六进制 d=十进制 s=字符串 i=指令，b=1字节 w=4字节

其他常用

命令 简写 作用
info breakpoints i b 查看断点
watch 变量 — 变量变化时停下
backtrace bt 查看调用栈
display 变量 — 每步自动打印
set var x = 5 — 修改变量值
info registers i r 查看寄存器

十、GCC 编译

编译四步：预处理 -E → 编译 -S → 汇编 -c → 链接

参数 作用
-o 名字 指定输出文件名
-std=c11 指定 C 标准（c99/c11/c17）
-I 目录 加头文件搜索路径
-L 目录 / -l库 加库搜索路径 / 链接库
-O0~O3 优化级别，调试时用 O0

常用的就这些，用多了自然就熟了
