K近邻:

KNN是一种基于实例的监督学习算法，通过计算新样本与训练集中所有样本的距离，找出最近的K个邻居，然后根据这K个邻居的多数类别（分类）或平均值（回归）来预测新样本的标签。

第四讲

神经网络非常大，手工写梯度公式不现实

计算图（Computational Graph）— 核心摘要

1. 定义

有向无环图（DAG），节点 = 运算/变量，边 = 数据依赖。用于描述数学表达式的计算流程。

2. 两大阶段

阶段 方向 做的事
前向传播 输入 → 输出 执行运算，计算结果，保存反向所需的中间值
反向传播 输出 → 输入 沿图逆序，应用链式法则，计算损失对各参数的梯度

3. 每个节点的标准接口

4. 链式法则在计算图上的表达

节点接收上游梯度 ∂L∂out ，乘上局部梯度 ∂out∂in ，传递给下游。

公式：

∂L∂in=∂L∂out⋅∂out∂in

5. 分支节点梯度处理（重点）

一个输出被多个下游节点使用时，反向到此节点的梯度需要累加（sum），不是覆盖。

6. 前向需保存的中间值（常见算子）

算子 保存内容
加法 无（局部梯度为常数1）
乘法 两个输入
ReLU 输入（或 >0 的掩码）
矩阵乘法 两个输入矩阵
Softmax 输出值
BatchNorm 均值、方差、输入

7. 两种构建模式

动态图 静态图
构建时机 运行时 运行前
代表 PyTorch TensorFlow 1.x / JAX
调试 容易 较难
性能 有Python开销 可做图优化

8. 显存优化技术

  • 梯度检查点：不存全部中间值，反向时重新前向计算（用时间换空间）
  • 算子融合：多个小操作合并成一个内核，减少显存读写

一句话总结：计算图是自动微分的载体，前向存中间值，反向传梯度，节点自治，框架调度。

第五讲

卷积把像素组合成了特征

第一部分：CNN 的四大哲学根基（它凭什么有效？）

  1. 局部感受野：全连接网络认为“像素远隔千里也有关联”，这导致参数量爆炸。CNN 认为**“近朱者赤”**——图像中，只有相邻的像素才有强相关性。每个神经元只需关注输入数据的一个小局部（如 3x3 区域）。
  2. 权值共享：一个在图像左上角检测“竖线”的卷积核，移动到右下角时参数完全不变。这赋予了 CNN 平移不变性（无论猫在画面哪里，同一个卷积核都能找到它），同时将参数量从百万级骤降至几百级。
  3. 层次化特征提取：CNN 是一台“从具体到抽象”的提取机。浅层学点线面（边缘、颜色斑块），中层学组件（眼睛、轮子），深层学语义（人脸、汽车）。
  4. 空间维度保持：与全连接层压平输入不同，卷积操作保持输入的二维拓扑结构（高和宽），这让网络能理解“上下左右”的位置关系。

第二部分：五大核心部件（网络由什么构成？）

一个标准的 CNN 通常由以下 5 种层堆叠而成：

  • ① 输入层：原始像素矩阵（如 224×224×3 ）。通常需要归一化（减均值除方差），防止梯度爆炸。
  • ② 卷积层：特征提取的核心引擎。包含多个可学习的卷积核（滤波器）。它们在输入上滑动，做点积运算（注意：不是矩阵乘法，是逐元素乘加）。
  • ③ 激活函数层：引入非线性。早年用 Sigmoid（易饱和），现在ReLU（线性修正单元）及其变体是绝对主流（计算快、缓解梯度消失）。
  • ④ 池化层：降采样操作（如 Max Pooling / Average Pooling）。作用是增大感受野、降低计算量、提供轻微的平移不变性（微小位移不影响最大响应值）。注意：现代大模型（如 ViT）已开始摒弃池化，用步长卷积替代。
  • ⑤ 全连接层：网络的“决策者”。位于末端，将卷积提取的高维特征图压平（Flatten），映射到样本标签空间（如分类的 1000 个类别）。
    好的，我们来把第四部分：现代CNN的进化彻底掰开揉碎。这不仅是网络结构的堆叠史，更是一部解决“深度”带来的顽疾的战役史。

为了让你获得“肌肉记忆”般的理解，我们不讲抽象概念，而是直接代入**“信号如何穿过网络”**的第一人称视角。

进化起点：直筒网络的致命伤（梯度消失）

早期的AlexNet（8层）和VGG（19层）是“直筒”——数据像子弹一样从枪口（输入）打进，必须笔直穿透枪管（每一层）到达枪托（输出）。

数学灾难：假设每层反向传播时梯度乘以权重 w （通常 |w|<1 ）。经过50层后，梯度变成 0.950≈0.005 。浅层卷积核几乎接收不到梯度，它们永远不会更新，网络陷入“前50层随机瞎猜，后50层拼命拟合”的死局。

进化一：残差连接 —— 深度网络的“高速公路”与“差分放大器”

（这是CNN历史上最伟大的单一突破，2015年ResNet提出）

1. 结构颠覆
传统直筒： 输出=卷积层(输入) （记为 F(x) ）
残差块： 输出=卷积层(输入)+输入 （记为 F(x)+x ）

2. 彻底改变学习目标
网络不再苦学“这张图到底是什么”（这是大海捞针），而是只学**“输入和输出之间的细微差异（残差）”**。

  • 直观比喻：让你画一头大象（ x ），如果直接画，很难。但如果给你一张模糊的象图（ x ），让你只修改画错的小细节（比如把鼻子加长点，耳朵改圆点，即 F(x) ），这就极其简单。
  • 数学铁壁：反向传播时，梯度路径有两条：一条穿过卷积层（可能衰减），另一条直接恒等映射（梯度 = 1，无损通过）。这保证了哪怕网络有1000层，浅层也能收到最强力的梯度信号。

3. 实战变体（你遇到的预训练模型大部分都是这个）

  • Bottleneck（瓶颈块）：用于ResNet-50/101。顺序是 1x1卷积（降维）→ 3x3卷积（空间提取）→ 1x1卷积（升维）。1x1卷积负责压缩计算量，使得3x3卷积只在极低的通道数（如64）上运算，速度极快。

进化二：空洞卷积 —— 不增加参数却“撑大”感受野

（专为语义分割、目标检测等密集预测任务而生）

1. 核心痛点：如果想看到更大的范围（感受野），传统做法是堆叠更多层或加大卷积核（如7x7）。但这要么让网络变慢，要么让参数量爆炸。
2. 惊人之举：在3x3的卷积核像素之间插入空洞（0值间隔）。

  • rate=1：标准3x3，感受野3x3。
  • rate=2：相当于5x5的核（但只有9个点有参数，中间插了0），参数量不变，感受野扩展到5x5。
  • rate=4：感受野扩展到9x9。

3. 别名“Atrous Convolution”：如同在密集的像素中打井，让你站在3楼（小核）却能俯视9楼（大感受野）的风景。常用在DeepLab系列中，在不缩小特征图尺寸的前提下聚合多尺度上下文信息。

进化三：1x1卷积 —— 通道间的“外交部长”

（由Network in Network提出，被Google Inception发扬光大）

很多人初见1x1时不屑一顾：“1x1能提取什么空间特征？” 但它根本不看空间，它只做一件事：跨通道的特征融合。

  • 假设输入： 56∗56∗256 。
  • 操作：1x1卷积核本质是一个长度为256的权重向量。它在每个像素位置上，将256个通道的数值进行加权线性组合，输出一个新值。
  • 两大神效：
    1. 灵活降维：用32个1x1核，瞬间把256通道压成32通道，计算量骤降（后续3x3卷积的运算量只有原来的1/8）。
    2. 增加非线性：先降维，后接ReLU，再升维，这相当于在通道维度上引入了一个“小型全连接网络”，极大提升了模型的表达能力。

进化四：深度可分离卷积 —— 移动端的“省油利器”

（MobileNet、EfficientNet的基石，将标准卷积的计算量砍到1/9）

1. 拆解标准卷积：标准卷积是“空间提取+通道融合”一步到位。
2. 强行拆分两步：

  • 第一步（Depthwise，逐深度卷积）：输入有几个通道，就用几个独立的2D卷积核。只提取空间特征，绝不融合通道。输入3通道，输出仍是3通道（计算量 = 3×3×3×H×W ）。
  • 第二步（Pointwise，逐点卷积）：用1x1卷积对上一步的输出进行通道融合，升降维度全靠这一步

计算量对比

  • 标准卷积
    计算量为：
    K x K x C_in x C_out

  • 深度可分离卷积
    计算量为：
    K x K x C_in + C_in x C_out

当输出通道数 C_out 较大时，深度可分离卷积的计算量约为标准卷积的 1/9 ~ 1/8。

进化五：分组卷积与Shuffle —— 多GPU的“协作分赃”

  • 起源：2012年AlexNet用两张GTX 580训练，被迫将卷积核分成两组，分别在不同GPU上运算，这叫分组卷积（Group Convolution）。
  • 现代妙用：分组卷积切断了组间信息交流（信息隔离），导致性能下降。ShuffleNet 发明了“通道混洗”（Channel Shuffle）：将分组卷积后的输出通道重新打乱排列，再送入下一组，相当于强制不同组之间“互通有无”，在不增加计算量的前提下恢复了信息流通。

进化六：动态卷积与注意力机制（CNN的“开眼看世界”）

（2020年后，CNN吸收了Transformer的注意力思想）

1. 传统静态卷积：卷积核训练完后，无论输入是猫还是车，核权重一动不动。这很死板。
2. 动态卷积（CondConv/DY-CNN）：根据输入图像的内容，动态加权组合多个卷积核。比如输入模糊，就用锐化核权重高一点；输入纹理丰富，就用平滑核权重高一点。每个样本都有专属的卷积核。
3. 通道注意力（SENet，2017年ImageNet冠军）：它像一个“内部监工”，先全局池化压缩每个通道为一个数值，然后用全连接层学习出每个通道的重要性权重（0~1之间），再乘回原特征图。重要的通道（如“眼睛”特征）放大，不重要的（如“背景噪声”）抑制。这是第一个将注意力引入CNN的里程碑。

终极认知：现代CNN的“标准模板”

现在（2026年），你在工业界看到的最标准CNN（如ResNeXt、EfficientNet）基本遵循以下黄金组合：

前段（Stem）：一个大步长卷积 + 最大池化（快速压缩空间尺寸）。
中段（Body）：堆叠 “残差连接 + 深度可分离卷积（或分组卷积） + 通道注意力（SE模块）” 的复合块。这是效率与精度的平衡点。
末段（Head）：全局平均池化（取代全连接层，减少过拟合） + 一个分类全连接层。

  • 池化层的池化之间最好不要有重叠，因为我们的目的是减少样本量，而不考察区域之间的相关性 作用是增大感受野、降低计算量、提供轻微的平移不变性（微小位移不影响最大响应值）。注意：现代大模型（如 ViT）已开始摒弃池化，用步长卷积替代。
  • 残差网络:输出等于卷积层(输入)+输入，可将梯度直接回传到起点
